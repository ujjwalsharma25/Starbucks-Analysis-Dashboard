☕**Starbucks Beverage Analysis — Power BI Dashboard**☕
Brewing Insights. Fueling Connections.

An interactive Power BI dashboard analyzing Starbucks' global beverage menu — covering caffeine content, calories, sugar levels, and category-wise distribution across 33 beverages.

📊 **Dashboard Overview**
<img width="1325" height="741" alt="Screenshot 2026-08-11 165821" src="https://github.com/user-attachments/assets/eaed4777-a1ca-46cf-b014-bd2a62787b2c" />

The report provides a 360° view of Starbucks beverages through KPIs, category breakdowns, and interactive filters:

Key Metrics: Total Beverages, Average Sugar, Average Calories, Average Caffeine

Average Calories by Beverage Category — trend line highlighting calorie-dense categories

Starbucks Global Presence — donut chart showing beverage category share (Classic Espresso, Frappuccino, Shaken Iced Beverages, Coffee, etc.)

Beverage Category Distribution — bar chart of average caffeine by category

Average Caffeine by Category — horizontal bar comparison (White Chocolate, Tazo Green Tea, Java Chip, Hot Chocolate, Caffe Mocha)

Top 5 Highest Caffeine Beverages — card-based visual spotlighting the most caffeinated drinks (Classic Espresso, Coffee, Frappuccino Blended, Frappuccino Light, Iced Beverages)

🎛️ **Interactivity**
Protein Range slider (0–20g) for filtering beverages by protein content

Beverage Prep dropdown/checklist slicer

Cross-filtering across all visuals for drill-down analysis

🛠️ **Tools & Techniques Used**
Power BI Desktop — data modeling, DAX measures, visual design

DAX — calculated measures for Average Calories, Sugar, Caffeine

Custom theming with Starbucks brand colors (#00704A, #1E3932)

Data cleaning: fixed caffeine column data type (Text → Numeric), resolved map visual issues from ISO alpha-2 country codes

Custom card layout for Top 5 Highest Caffeine Beverages section
📁 **Files**
Starbucks-Analysis.pbix — Power BI report file
Dataset: Starbucks beverage nutrition data (calories, caffeine, sugar, protein, category)

📌 **Key Insights**
Average caffeine across all beverages: 81 mg
Average calories: 194.30 kcal
Classic Espresso leads in caffeine content at 293.75 mg
Coffee and Frappuccino categories dominate the beverage mix
